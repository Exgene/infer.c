# infer.c

A very minimal inference engine written in C (and in future in C+Cuda).

## Reason

I wanted to learn how an inference engine would work, What are the optimizations made both in CPU level and GPU level. Always been fascinated with math and systems programming so whats a better way to learn ;).

Also can brush up with the Math required for LLMs as well so its a win win situation.

## Current

Currently implementing a very minimal implementation (for now CPU only and probably very bad) and slow version. Will iterate and improve performance after that.
